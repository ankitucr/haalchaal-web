# Haal Chaal - Premium Secure Messaging Website

Official landing page and web application interface for **Haal Chaal** — India's premier secure messaging experience featuring a glassmorphic UI, fluid dual themes, and an interactive live 3D mobile preview.

## ✨ Key Features
* **Glassmorphic UI Architecture:** Modern, sleek, and translucent design with high-end visual depth and smooth blur effects.
* **Dual Theme Support:** Seamless toggle between default *HaalChaal Mode* (Light) and an enhanced *Dark Mode* with glowing ambient lighting.
* **Interactive 3D Phone Mockup:** Real-time simulated mobile interface showcasing chats, status updates, and animated typing indicators.
* **Dynamic Particle Engine:** Background canvas particles and ambient glowing meshes for an immersive user experience.
* **Direct APK Download:** Integrated link pointing straight to the latest stable Android release.

## 🛠️ Tech Stack
* **HTML5 & CSS3:** Custom CSS variables, transitions, and advanced glassmorphism styling.
* **Tailwind CSS:** Utility-first styling framework for responsive layouts.
* **Vanilla JavaScript:** Powers the live chat simulator, tab navigation, theme engine, and particle animations.
* **FontAwesome & Google Fonts:** Clean typography (Inter) and rich iconography.
